# Spotlight

This repo is a hugo page that showcase the images that I like in [windows spotlight](https://en.wikipedia.org/wiki/Windows_Spotlight) with description found by clicking the "more info" link.

One can find the image looking in devtools for the following element or `#bcg-img-url`
```html
<div class="media-container" id="bcg-img-url" style="background-image:url
```
